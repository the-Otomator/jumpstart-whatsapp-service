3 · השעיה — מסך הצוות

החשבון הושעה

החשבון הושעה בגלל תשלום שלא הוסדר. הדפים הציבוריים אינם זמינים. הסדרת התשלום תחזיר הכל מיד, כולל ההגדרות.
מבוסס על מסך החסימה הקיים (TrialBlockedScreen, מצב תשלום) — רק הכותרת המשנית מתעדכנת. עובד שאינו בעל החשבון: "פנו לבעל החשבון" כמו היום.
